\# Configuração das Variáveis



1\. \*\*Abrir variáveis\*\*  

&#x20;  - Aceda ao ficheiro de configuração ou ao ambiente onde as variáveis estão definidas.



2\. \*\*Alterar o valor das variáveis\*\*  

&#x20;  - Atualize os caminhos das seguintes variáveis para os diretórios correspondentes na sua máquina:  

&#x20;    - `ErrorFilesPath`  

&#x20;    - `SrcFilesPath`



3\. \*\*Configuração do servidor de base de dados\*\*  

&#x20;  - Por padrão, o valor de `DbServer` está definido como `localhost`.  

&#x20;  - Se o \*\*ServerName\*\* da sua máquina for diferente, modifique o valor de `DbServer` para corresponder ao nome correto.
